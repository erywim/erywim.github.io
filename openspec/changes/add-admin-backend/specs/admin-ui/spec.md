## Purpose

在静态站点内提供隐藏的像素风后台控制台 `/eeeeerywim`：登录前不暴露任何管理数据，登录后提供九个内容域的列表与编辑、发布控制与状态反馈，视觉复用站点既有红白机组件体系。

## ADDED Requirements

### Requirement: 隐藏路由

后台 SHALL 部署在 `/eeeeerywim` 路径：不出现在公开导航与站点地图（sitemap）中，并声明 `noindex`。页面本身为静态资源，不内嵌任何管理数据。

#### Scenario: 搜索引擎不收录
- **WHEN** 抓取站点地图或首页 HTML
- **THEN** 不存在指向 `/eeeeerywim` 的链接，且该页含 noindex 标记

### Requirement: 像素登录界面

未登录访问 `/eeeeerywim` SHALL 只呈现像素风（RPG 密码界面风格）登录表单；登录前不发起任何管理数据请求。凭据错误在界面内提示，不跳转。

#### Scenario: 登录前零数据暴露
- **WHEN** 未登录状态打开后台页并审查网络请求
- **THEN** 除静态资源外无管理 API 调用，页面无内容数据

#### Scenario: 登录成功进入工作台
- **WHEN** 输入正确账号密码提交
- **THEN** 界面切换为管理工作台

### Requirement: 九域管理工作台

登录后 SHALL 提供九个内容域的导航与对应视图：列表（按时间倒序、含脏标记/待删除标识）、新建、编辑表单（字段与各域 schema 对应，枚举用选择器、列表型字段可增删排序）、软删除与恢复。勇者档案为单记录编辑表单。

#### Scenario: 列表脏标记可见
- **WHEN** 3 篇文章中 1 篇有未发布修改
- **THEN** 列表中该篇带「待发布」标识，顶栏显示待发布总数

#### Scenario: 编辑灵感火花的目标清单
- **WHEN** 管理员在 quest 编辑表单增删目标条目并勾选完成态
- **THEN** 保存后重新打开表单，清单内容与勾选态一致

### Requirement: 发布与同步控制

工作台 SHALL 提供条目级「发布」按钮、「全部发布（N）」按钮与「从仓库同步」按钮，并展示每项操作的结果：发布成功、发布失败（字段级错误）、同步完成、冲突待处理。

#### Scenario: 全部发布反馈
- **WHEN** 点击「全部发布（3）」且第 2 条失败
- **THEN** 界面报告 1 条成功、1 条失败及原因、1 条未执行

### Requirement: 冲突处理界面

当目标条目检测到仓库手改冲突时，编辑视图 SHALL 呈现明确选择：「拉取仓库覆盖本地」或「强制发布覆盖仓库」，选择前保存按钮禁用。

#### Scenario: 冲突时禁改
- **WHEN** 打开存在冲突的条目
- **THEN** 显示冲突提示与两选项，未处理前不能保存该条目

### Requirement: 会话状态与登出

工作台 SHALL 显示当前登录身份与登出入口；任何管理请求返回 401 时自动回到登录界面且不残留已加载的管理数据。

#### Scenario: 会话过期自动回登录
- **WHEN** 会话过期后在工作台内发起任意管理请求
- **THEN** 界面回到登录页，DOM 中不再保留此前加载的内容数据
